# ERASURE

**An Independent Narrative Mystery Visual Novel**

*One message. A mystery waiting to unfold.*

## About the Game

**ERASURE** is an independently developed narrative-driven mystery visual novel built with Ren'Py.

At exactly **9:33 a.m.**, Liana Voss receives a mysterious message from an unknown sender. What begins as an unexpected interruption sets off a chain of events involving secrets, relationships, hidden information, and choices with potentially far-reaching consequences.

The game combines cinematic storytelling, interactive dialogue, branching narrative choices, character-driven scenes, puzzles, and atmospheric audio.

## Game Structure

The current development project includes:

- **Prologue** — Introduces the world, atmosphere, and foundations of the mystery.
- **Chapter 1: The Message** — The mysterious message begins Liana's investigation.
- **Chapter 2** — Continues the unfolding investigation and expands the narrative through character interactions and player decisions.

Development is ongoing, with additional refinement, testing, and content planned.
